# 学习闭环改版验收（2026-10-02）

本轮在现有 Flutter 客户端上改版，没有重写 Python 后端、修改排期 reducer 或新增同步事件类型。保留本轮开始前已有的未提交改动；未提交 Git、未推送或发布云端。

## 阶段 1：实际题库与可信状态

- `features/library/catalog.dart` 是运行时题目目录，按唯一 ID、当前考试方向、非演示题计算；50 道为学科常规练习门槛，不表示覆盖完整。
- 首页、题库、离线设置共享目录统计。占位学科显示建设中，不开放常规新题练习；已有历史题目仍可复习。
- 内置综合库 3520 个唯一 ID：3504 道资料整理题、16 道演示题。修复 1104 / 8 章；牙周 1200 / 17 章；口外 1200 / 23 章。当前均待审核，不能作为已核验真题宣传。
- 考研可练 3504，执医可练 1200，本科期末当前无达门槛学科。外部 `question-bank/` 的 3649 题草稿不参与运行题量；分库已在综合库中，不重复相加。
- 修复综合库启动时未加载下载缓存的问题；同 ID 缓存按原更新机制覆盖，保留历史题目引用。
- 验收：题库 → 三个学科卡 → 建设中列表；切换执医/本科期末；对照今日与我的 → 下载/更新离线题库中的题数。
- 风险：资料题尚需专业审核；没有修改任何题干、答案、ID 或审核字段。

## 阶段 2：今日计划与续练、答题结算

- `features/today/` 负责当天计划视图，不替代原排期。每轮最多 20 道到期题、10 道新题，并遵守每日目标和额度；到期题超出本轮时先继续复习。
- 今日主按钮默认逐题深度模式；已完成数按当天不同题目计数，分母为已完成加本轮剩余任务。自定义练习可选学科、章节、题量、随机和三种已有模式。
- `features/practice/` 复用原深度、批量、速刷组件和事件，增加统一工具条与结算。结算含完成数、客观题正确率、用时、错题、薄弱章节、下次复习以及三个后续动作。
- `session_journal.dart` 只存本机元数据：原题目 ID 列表、答案、评级、位置、已提交 ID、关联事件 ID、开始时间、累计用时、模考原截止时间。事件与已提交 ID 写入同一个账号存储值，避免恢复时重复计分。
- 旧版仅存剩余题目的续练记录迁移为兼容断点，不虚构旧答案或旧耗时。用时后台暂停；每次交互和每 5 秒检查点保存。
- 验收：今日 → 开始计划 → 作答/看解析 → 返回并确认结束 → 续练卡 → 刷新网页 → 继续；批量模式完成选择、进入统一解析、退出恢复；速刷答错退出恢复；完成后检查结算和三个入口。
- 风险：断点与耗时目前仅在本机浏览器/账号命名空间保存，不跨设备同步。浏览器强制终止可能丢失最后几秒计时，不能代替正式考试权威计时。

## 阶段 3：题库、题本和学情

- 题库为学科 → 章节 → 题目，预览每批 20 题；学科有题量、章数、已学、正确率和待复习；章节有完成度、错题数、最近日期和三个操作。右上角练习可选三种模式。
- 题本首屏错题/收藏/疑问题数量；筛选默认折叠，空结果有原因与清空入口。实际练习数同时受范围、到期优先、新题目标、额度限制。
- 疑问题直接复用最新 `grade=guessed`，不新增事件。学情按北京时间统计周数据，薄弱章节可下钻并启动巩固；七天无作答有明确空状态。
- 验收：题本 → 筛选 → 输入无匹配词 → 清空筛选；学情 → 薄弱章节 → 巩固；新访客查看七天无数据状态。
- 风险：正确率按客观题作答次数统计，题数按题目去重，不能直接相除推算；小样本建议仅供参考。学习时间按会话开始日期归属，只包含新版本机记录。

## 阶段 4：主题、入场动画与结构

- `main.dart` 仅保留启动逻辑；`app/` 放应用壳和共享样式；各页面按 `today/library/notebooks/statistics/profile/practice` 分目录。
- 青绿、湖蓝、紫藤、暖橙、玫瑰使用同一深浅比例；页面背景为白色与主色 4.5% 混色，卡片保持白色。主题切换同步刷新图标、选中标记和背景并保存偏好。
- Web 加载前展示齿间品牌淡入，首帧移除；进入应用有 550ms 淡入/轻微位移，不阻塞操作。尊重系统减少动态效果设置。
- 验收：我的 → 主题色 → 返回今日 → 刷新；检查淡背景及选中色；在系统减少动态效果开启时检查无入场位移。
- 未引入大型依赖。未改支付或邮箱验证码部署状态，不将现有开发支付入口视为已上线收款能力。
